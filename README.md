# 데일리 수학

매일 한 문제씩 푸는 수능 단답형 스타일 수학 문제 사이트입니다.

## 문제 추가하기

`problems/` 폴더에 `연-월-일.txt` 파일을 하나 만들면 그날의 문제가 됩니다.
GitHub에서 **Add file → Create new file**을 누르고 이름 칸에 `problems/2026-11-19.txt`처럼 적습니다.
월과 일은 두 자리로 씁니다. 파일을 저장(Commit changes)하면 1분쯤 뒤 사이트에 반영됩니다.

### 파일 형식

```
points: 3
answer: 40
---
함수 $f(x)=11x^2+18x$에 대하여 $f'(1)$의 값은?
---
$f'(x)=22x+18$ 이므로
$f'(1)=22+18=40$
```

- 첫 번째 `---` 위: `points`(배점, 생략 가능)와 `answer`(정답, 0 이상 999 이하의 정수)
- 두 `---` 사이: 문제 본문
- 두 번째 `---` 아래: 해설(생략 가능)
- `---`는 한 줄에 그것만 적습니다.

### 선택 기능

- **조건 상자**: 문제 본문에서 `> `로 시작하는 줄은 상자 안에 들어갑니다.
  ```
  > (가) $a_1=2$
  > (나) $a_{n+1}=2a_n$
  ```
- **그림**: 맨 위에 `figure: figures/2026-11-19.svg`처럼 적고, 그 그림 파일을 `figures/` 폴더에 올립니다.

### 수식 쓰는 법

`$` 와 `$` 사이가 수식입니다. 역슬래시는 한 번만 적습니다.

| 쓰고 싶은 것 | 입력 |
| --- | --- |
| 거듭제곱 | `x^2`, `x^{10}` |
| 아래첨자 | `a_n`, `a_{n+1}` |
| 분수 | `\frac{a}{b}` |
| 근호 | `\sqrt{x}` |
| 미분 | `f'(x)` |
| 부등호 | `\le` `\ge` `\ne` |
| 기타 기호 | `\times` `\cdot` `\pm` `\to` `\infty` `\int` `\sum` `\pi` `\theta` |
| 함수 | `\sin` `\cos` `\tan` `\log` `\ln` `\lim` |
| 수식 안의 한글 | `\text{...}` |
